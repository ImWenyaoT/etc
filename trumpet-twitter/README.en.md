# Trumpet

A small Twitter clone: React + Express + SQLite with auth, following timeline, posts/replies, likes, and profiles.

## Quick start

```bash
pnpm install
pnpm build
pnpm --filter @trumpet/api seed
pnpm dev
```

- Web: http://localhost:5173
- API: http://localhost:4000

See [docs/architecture.md](./docs/architecture.md).
