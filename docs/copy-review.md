# 五个项目页面文案对照稿

范围：当前仓库五个项目的页面标题、导航、按钮、字段、说明、空状态、加载状态和页面可见错误。本稿已获确认，文案已应用至页面；功能和校验规则保持不变。用户填写的内容、昵称、账号、帖子、示例代码及原始运行数据不改。

规则：名称2～4个汉字；说明每条不超过20字；同一动作统一用词。品牌、格式名、数字和单位保留。算法指标按已确认偏好保留准确名称，并配白话解释。表格中的“（保留）”与“（保留默认值）”是编辑标记，不显示在页面上。多行新文案中，首行为名称，后续行为各不超过20字的独立说明。

设计依据：让用户从名称看出动作和结果，删除修辞性口号；以统一用词和相邻说明建立层级。这是把《Don't Make Me Think》的易懂目标以及《写给大家看的设计书》的重复、亲密性原则用于文案的具体方案，不代表原书逐字规则。[作者网站](https://sensible.com/)、[出版社介绍](https://www.pearson.com/en-us/subject-catalog/p/Non-Designer-s-Design-Book-The-4th-Edition/P200000000691?view=educator)。

以下“原文案 → 新文案”来自当前页面源码；同义加载状态在一行合并。错误行包括接口可能直接展示到页面的消息，原始技术详情可继续保留在日志或详情中，不作为首要提示。

## 必须保持的功能边界

- “关注动态”包含自己和关注对象的帖子，说明中明确写出“自己”。
- “查找用户”要求完整账号，不能写成“搜索昵称”或暗示模糊搜索。
- “历史最高”只记录于当前浏览器，不能写成全站纪录或排行榜。
- 文档转换仍输出 JSON，不承诺多种输出格式；JSON、YAML、XML 不改成中文代称。
- “读取用时”仍对应中序遍历，不误写成“排序总用时”；“旋转次数”和“黑高”保持准确算法含义。
- “取消关注”“已赞”必须按当前状态展示，不改变按钮操作。
- 密码下限按字符、上限按 UTF-8 字节计算，不能将“8～72字节”直接改写成“8～72字”。本稿使用“账号或密码不符合要求”，更细的密码长度提示需与现有校验方式一致。
- 名称限制不套用到用户内容、动态账号、品牌、格式、指标单位及原始数据字段。原始 JSON 键保持不变，避免破坏复制结果。
- 程序发生异常时，按真实失败原因显示提示，不把错误写成“无结果”。文件夹访问等系统错误归为“无法读取文件，请联系管理员”，具体路径和系统原因留在技术详情。
