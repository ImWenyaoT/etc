# Snake

Standalone Next.js fullstack app: classic snake with local best score and a scores board.

## Setup

Requires Node.js 22+ and pnpm 10+.

```sh
pnpm install
pnpm dev
```

Open `http://localhost:18104`. Scores path comes from `SCORES_FILE` (default `data/scores.json`).

## Check

```sh
pnpm test
pnpm build
```
