# Snake

Pure frontend TypeScript Canvas snake game. Rules are decoupled from rendering and unit-tested under Node.

## Quick start

```bash
pnpm install
pnpm dev
pnpm test && pnpm typecheck && pnpm build
```

Arrow keys / WASD to move, Space to pause.

See [docs/architecture.md](./docs/architecture.md).
