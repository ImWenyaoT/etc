# JSON / YAML / XML Parser

Standalone Next.js fullstack app: normalize JSON, YAML, or XML into readable JSON.

## Setup

Requires Node.js 22+ and pnpm 10+.

```sh
pnpm install
pnpm dev
```

Open `http://localhost:18102`.

## CLI

```sh
pnpm cli -- parse <file> [--format|-f json|yaml|xml]
```

## Check

```sh
pnpm test
pnpm build
```
